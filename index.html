01

EVENT BOOKING REST API

BACKEND ARCHITECTURE // SQL & SEQUELIZE
Node.js Express.js TypeScript MySQL Sequelize JWT RBAC
The Problem

Multi-tenant community event booking platforms suffer from schedule conflicts, overlapping bookings, late cancellations that leave organizers with unpaid reservations, and slow queries when discovering localized gatherings within driving distance.

The Solution & Architecture

Engineered a hardened RESTful backend in Node.js and TypeScript utilizing MySQL with Sequelize ORM. Implemented atomic transaction isolation for overlapping booking prevention, spatial Haversine trigonometry for 30 km radius search, and time-gated cancellation middleware.

Key Verified Features
Event Creation & Management: Complete lifecycle with organizer ownership and participant limits
30 km Location Discovery: Haversine mathematical radius queries for nearby events
Overlap Prevention: Atomic schedule validation preventing concurrent double bookings
8-Hour Cutoff Restriction: Strict time-gated cancellation window safeguarding organizers
Ownership Security: Authorization guards preventing unauthorized ticket cancellations
JWT & RBAC: Role-based access control isolating organizers from attendees

02

ORDER MANAGEMENT API

TRANSACTIONAL COMMERCE // MONGODB & MONGOOSE
Node.js Express.js TypeScript MongoDB Mongoose Joi Validation
The Problem

E-commerce checkout pipelines risk inventory count drift during high-concurrency bursts, abuse from customer purchase spam, insecure user credentials, and lack of operational order data exports for store managers.

The Solution & Architecture

Engineered a robust order management API in TypeScript and Express.js on MongoDB. Integrated Joi payload sanitization middleware, rate-gated customer checkout quotas (max 5/day), atomic stock validation, and streaming CSV order reporting.

Key Verified Features
Full Entity Lifecycle: Users, Products, Wishlists, Orders, and Purchases
Max 5 Purchases/Day: Business logic quota preventing hoarding and checkout bot spam
Atomic Stock Validation: Quantity decrements verified against catalog counts
Streaming CSV Reports: Administrative order export with dynamic date-range filtering
Joi Schema Validation: Pre-route payload sanitization blocking bad requests
Auth & Password Reset: JWT tokens, bcrypt salting, and secure reset workflows
View GitHub Repository Hire for E-Commerce API
03

SWEET SHOP MANAGEMENT & INVENTORY SYSTEM

ENTERPRISE INVENTORY // ATOMIC NO-SQL CONCURRENCY
Node.js Express.js MongoDB Mongoose JWT RBAC Postman
The Problem

Simultaneous orders on high-demand inventory items cause race conditions where stock counts drift into negative values, while non-admin users could potentially tamper with product pricing and stock quantities.

The Solution & Architecture

Engineered an Express.js backend using MongoDB atomic $inc operators with quantity: { $gte: count } query guards. Built role-based admin endpoints for restock operations and automated Postman test suites to prevent regressions.

Key Verified Features
Atomic $inc Decrements: Prevents race conditions during simultaneous sales
Zero-Stock Guard: Returns structured HTTP 409 Conflict when items sell out
Admin Restock Portal: Secure endpoints restricted to authenticated managers
Uniform Error Envelopes: Centralized exception handler with informative codes
Postman Test Collection: Automated pre-flight endpoint and regression tests
Responsive Frontend UI: Visual inventory dashboard for retail operations
View GitHub Repository Hire for Inventory System
04

AI HERITAGE SPATIAL MULTIMEDIA GUIDE

SPATIAL COMPUTING // AI INTEGRATIONS & STREAMING
Node.js Express.js MySQL Spatial Google Gemini AI Audio Streaming Responsive UI
The Problem

Monuments and heritage tourists require accurate, context-aware architectural knowledge on-site, yet dedicated hardware guides are expensive and manual tour scripts are rigid and unengaging.

The Solution & Architecture

Architected a full-stack spatial web application that queries MySQL spatial databases for nearby landmarks, generates cultural narratives on-the-fly using Google Gemini AI prompt orchestration, and streams chunked audio narration to mobile visitors.

Key Verified Features
Proximity Geo-Queries: Real-time distance calculation for historical monuments
Gemini AI Narratives: Dynamically generated historical context and highlights
Chunked Audio Streaming: Progressive audio delivery with low startup latency
Mobile Tourist UX: High-contrast responsive interface optimized for field use
API Key Isolation: Server-side proxy shielding sensitive Gemini AI credentials
Fallback Resilience: Cached local narratives served when offline or low connectivity
